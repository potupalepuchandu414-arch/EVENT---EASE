# 🧠 Problem Solved

Traditional event booking systems often suffer from:

❌ Double bookings  
❌ Poor scheduling  
❌ Lack of real-time updates  
❌ Unorganized vendor management  

### EVENT-EASE solves these issues through:

⚡ Instant availability updates  
⚡ Secure booking workflows  
⚡ Conflict-free scheduling logic  
⚡ Scalable backend architecture

# 🧪 Installation & Setup

## Clone Repository

```bash
git clone https://github.com/yourusername/EVENT---EASE.git
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Backend Setup

```bash
cd backend
npm install
npm start
```
